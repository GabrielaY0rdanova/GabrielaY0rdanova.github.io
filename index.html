Flagship Project

PharmaMarket Data Platform

A four-stage end-to-end data project built on a real-world pharmaceutical dataset from Bangladesh — covering the full journey from raw CSV files to an interactive Tableau dashboard. Each stage builds directly on the output of the previous one.

ETL → Data Cleaning → EDA → Visualization

PharmaMarket ETL

A full ETL pipeline that extracts data from CSV files, parses complex multi-value fields, and loads it into a structured SQL Server database. Covers drug classes, generics, manufacturers, dosage forms, indications, and medicines — including package sizing, container pricing, and a many-to-many relationship between generics and indications.

Tools: SQL Server · T-SQL · BULK INSERT · CTEs · Window Functions

View on GitHub

PharmaMarket Data Cleaning

Data cleaning and quality validation project built on the ETL output. Inspects every table for NULLs, duplicates, encoding artifacts, and referential integrity issues — applying targeted fixes and documenting all findings in a separate clean database.

Tools: SQL Server · T-SQL · Python · Pandas · pyodbc

View on GitHub

PharmaMarket EDA

Exploratory data analysis built on the cleaned pipeline output, migrated to PostgreSQL. Explores the distribution, rankings, pricing and segmentation of 21,708 medicines across 240 manufacturers and 113 dosage forms in the Bangladeshi pharmaceutical market — through modular analytical SQL scripts covering magnitude, part-to-whole analysis, data segmentation, and comprehensive reports using CTEs and window functions.

Tools: PostgreSQL · SQL · CTEs · Window Functions · Python · Pandas · pyodbc

View on GitHub

PharmaMarket Visualization

Interactive Tableau dashboard built on the EDA outputs. Presents market structure, pricing patterns and generic competition across two dashboards connected via a Tableau Story — covering 21,708 medicines across 240 manufacturers and 113 dosage forms in the Bangladeshi pharmaceutical market.

Tools: Tableau Desktop · PostgreSQL · SQL · Tableau Public
